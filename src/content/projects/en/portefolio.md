## The challenge

I needed one place to show my work, from academic projects to websites for local clients, that was fast, easy to update and good for SEO.

## The solution

- Projects written in **Markdown** in a content collection with a Zod-validated schema.
- Technology filter in plain JavaScript, no framework, with the filter kept in the URL.
- Light/dark theme that follows the system preference.
- Portuguese and English versions using Astro's built-in i18n.

## Result

A static site hosted on Vercel, scoring above 95 in every Lighthouse category.
