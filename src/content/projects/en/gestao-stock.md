## Context

A project built for the CTeSP in Information Systems and Technologies at the University of the Algarve.

## Features

- Products, suppliers and stock movements.
- Alerts when a product falls below its minimum stock.
- Monthly report exportable as CSV.
- Session-based authentication and user roles.

## What I learned

Designing a REST API with Express, relationships between tables and manual testing with Postman.
