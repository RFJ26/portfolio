## The challenge

When maintaining several client websites, checking each one by hand was slow and easy to forget.

## The solution

A Node.js and TypeScript CLI that takes a list of URLs, runs Lighthouse with Puppeteer and generates an HTML report with:

- Performance, accessibility, best practices and SEO scores.
- Broken links and images without alt text.
- A comparison with the previous run.

## Result

I can see the state of every website in a single weekly report.
